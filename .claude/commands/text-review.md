Проверь текст **$1** (бриф: $2 — если не указан, найди в `content/briefs/` по теме/URL). Действуй по `CLAUDE.md` §4 и
`docs/agent-knowledge.md`. Делегируй `content-seo` (при необходимости `geo-ai` для AEO).

## Чек-лист (каждый пункт: OK / правка / блокер)
1. **Соответствие брифу:** целевой ключ в title/H1/первом абзаце, покрыты H2 из брифа, FAQ, объём, интент.
2. **Факты:** все тех-цифры (J/TH, TH/s, °C, %, совместимость моделей, результаты тестов) — сверены с живой страницей продукта
   (`./scripts/page-snapshot.py --urls <url>` / сырой HTML) или помечены `[VERIFY]`. Выдуманная цифра = **блокер**.
3. **Dev fee:** нигде нет «no dev fee / без комиссии / zero fee»; формулировка «transparent dev fee» + текущая ставка [VERIFY]. Иначе — блокер.
4. **Запреты:** обещания доходности/инвест-советы, юр-гарантии по юрисдикциям, упоминание `bixbitusa.io` как BiXBiT — блокер.
5. **Тон:** технический B2B (US English / нативный русский), без воды и маркетинговых клише; для EN — прогон через skill `humanizer` (AI-следы).
6. **On-page:** title ≤ 60, description 140–160, один H1, ALT у изображений, внутренние ссылки на продвигаемые страницы
   (по `content/internal-linking.md`), анкоры не переспамлены, внешние ссылки живые.
7. **AEO / Featured snippet:** прямой ответ в первом абзаце (40–60 слов), определения, таблицы/списки шагов, FAQ под PAA.
8. **Уникальность внутри сайта:** не каннибализирует существующую страницу (`data/cannibalization/`, поиск по `data/crawl-*/pages.json` title).
9. **Технически для публикации:** JSON-LD (Article/FAQPage) через сериализатор, hreflang-пара EN/RU, план переиндексации (`./scripts/index-submit.py`).

## Артефакт
`content/reviews/<slug>-review-YYYY-MM-DD.md`: вердикт (готов / после правок / блокер), таблица чек-листа, конкретные правки
(было → стало, цитатой не длиннее 2 строк), список [VERIFY] для инженеров. В чат — вердикт и блокеры.

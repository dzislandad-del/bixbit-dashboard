Дай SEO-рекомендации по макету **$1** для страницы/запроса **$2**. Действуй по `docs/agent-knowledge.md`.

## Шаги
1. Получи макет: ссылка Figma — через Figma MCP (`get_design_context` / `get_screenshot`, при необходимости `get_metadata` для
   текстовых слоёв); путь к изображению — прочитай файл. Не выдумывай содержимое, которого не видно.
2. Контекст страницы: текущая версия (`./scripts/page-snapshot.py --urls <url>`), бриф в `content/briefs/`, данные GSC по
   странице (`./scripts/gsc-query.py --dimensions query,page --page-contains <путь>`), позиции/AIO (`data/rank-tracking/`, `data/serp-features/`).
3. Проверь по макету (делегируй `content-seo`, `technical-seo`, `geo-ai`):
   - иерархия заголовков: один H1 с целевым ключом, логичные H2/H3; текст не в картинках;
   - контент первого экрана: что это, для кого, ключевое отличие — прямой ответ для AEO;
   - обязательные блоки из брифа (FAQ, таблица совместимости/спек — `[VERIFY]`, CTA, доверие/E-E-A-T);
   - перелинковка: меню/хлебные крошки/блоки «связанные» → продвигаемые страницы; нет ли потери существующих ссылок;
   - schema под тип страницы (Product/SoftwareApplication/FAQPage/BreadcrumbList) — какие данные из макета её питают;
   - CWV-риски: тяжёлые рендеры/видео на первом экране (LCP), слайдеры, шрифты, сдвиги макета (CLS), lazy-load;
   - мобильная версия (если есть фрейм), локализация EN/RU/ES (длина строк), переключатель языка.
4. Сравни с тем, что сейчас ранжируется (что нельзя потерять при редизайне: тексты, заголовки, ссылки, URL).

## Артефакт
`content/mockup-reviews/<slug>-YYYY-MM-DD.md`: сводка, таблица замечаний (блок макета | проблема | рекомендация | приоритет P0–P3),
тексты для заголовков/мета, что сохранить из текущей версии. В чат — топ-5 правок.

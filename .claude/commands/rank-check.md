Сними текущие позиции BiXBiT и сравни с baseline. Область: $ARGUMENTS (пусто = все ключи из
`data/rank-tracking/keywords.md`). Действуй по `RUNBOOK.md`/`CLAUDE.md` и `docs/agent-knowledge.md`.

## Шаги
1. `./scripts/check-connectors.sh` — убедись, что GSC отвечает. DataForSEO проверит сам скрипт.
2. `./scripts/serp-rank.py --dry-run` — покажи, сколько ключей и запросов будет.
   Бюджет: ~$0.018 за запрос (depth 100), 30 ключей ≈ $0.54–1.08.
   **Не используй MCP для массового съёма** — ~10k токенов на выдачу; скрипт делает то же без контекста.
3. `./scripts/serp-rank.py --out data/rank-tracking/rank-YYYY-MM-DD.json`
   (с `--keywords "..."`, если задан $ARGUMENTS). Скрипт сам: 1 задача на запрос, ретрай на 40101/40106
   и коротких выдачах, только `bixbit.io` (`bixbitusa.io` — партнёры, не учитываются), дельты к последнему baseline.
4. `./scripts/gsc-query.py --days 28 --dimensions query,page --country usa --out data/gsc-queries-pages-us-YYYY-MM-DD.json`
   и `--dimensions query` → `data/gsc-queries-us-YYYY-MM-DD.json`. Сопоставь с ключами: показы, клики, CTR, ср. позиция, страница.
5. Для `not_found_short_serp` решай по GSC, а не по SERP (короткая выдача ≠ не ранжируется).

## Классификация
- **P0-алерт:** ключ P0 выпал из топ-20 или просел > 5 позиций; сменился ранжирующий URL на нецелевой.
- **P1:** P1-ключ просел > 5; P0 просел 3–5; CTR по ключу в топ-5 = 0 при ≥ 50 показах.
- Флаги `volatile`, `partial_serp_40106`, `not_found_short_serp` — **не алертить** без подтверждения GSC.
- Рост ≥ 3 позиций — отметить как win.

## Правила
- Позиции — только из выгрузок. Не выдумывай и не «сглаживай» дельты.
- Позиция в GSC (среднее) и снимок SERP (один вызов, desktop) напрямую не сравниваются — показывай обе.
- Ротацию ключей только **предлагай** (кандидаты — запросы с показами в GSC вне списка); утверждает человек.

## Артефакт
`reports/rank-check-YYYY-MM-DD.md`: сводка (найдено / топ-10 / ↑↓ / стоимость), алерты P0/P1 наверху,
таблица ключ | позиция | было | Δ | GSC показы/клики/поз. | URL | флаги, кандидаты на ротацию.
Baseline не перезаписывай — новая норма утверждается человеком.
В чат — алерты и «N ключей, ↑X ↓Y, $Z».

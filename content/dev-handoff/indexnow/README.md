# IndexNow: файл ключа для корня сайта

**Что сделать (разработчик):** выложить файл `da09a0c06dc40b2885ced026502b666a.txt` из этой папки в корень сайта, чтобы он открывался по адресу

    https://bixbit.io/da09a0c06dc40b2885ced026502b666a.txt

**Требования:**
- ответ **200**, `Content-Type: text/plain; charset=utf-8`;
- тело — ровно ключ `da09a0c06dc40b2885ced026502b666a`: 32 символа, без пробелов, переводов строки и HTML-обёртки;
- никаких редиректов: ни на `/en`, ни на другую локаль. Правило «/ → /en» не должно цеплять этот путь;
- robots.txt этот путь не закрывает (сейчас не закрывает).

**Зачем:** IndexNow позволяет сразу сообщить Bing, Яндексу, Seznam, Naver и Yep, что страница изменилась. Отправку делает
`scripts/index-submit.py --urls ... --submit`. Ключ публичный по протоколу, это не секрет.

**При переезде `/ru` → bixbit.tech** на новом домене нужен свой файл ключа (тот же или новый ключ) в корне `bixbit.tech`.

**Проверка после деплоя:** `./scripts/index-submit.py --urls https://bixbit.io/en` (без `--submit`) должен написать
«IndexNow ключ-файл …: OK».

Теги и ALT для документации

Title, description и ALT для всех 58 страниц (29 EN и 29 RU) и 212 изображений. У каждой страницы есть готовый блок frontmatter и строки картинок в формате ![ALT](файл). Всё копируется кнопкой.

1. Конфиг сайтаДобавьте в .vitepress/config шаблон заголовка и hreflang (ниже), а в public/ — robots.txt.
2. FrontmatterВставьте блок в самое начало .md-файла страницы. Если frontmatter там уже есть, замените в нём title и description.
3. ALTЗамените строки картинок на скопированные. Файл картинки не меняется, меняется только текст в квадратных скобках.

Title задаётся без суффикса: « | BiXBiT Docs» добавит шаблон из шага 1. Отдельные og-теги во frontmatter не нужны, их уже выводит существующий transformHead сайта. Строки с пометкой «проверить» — там, где скриншот расходится с текстом страницы.

Конфиг VitePress

// .vitepress/config — добавить в существующий конфиг (не заменять transformHead, а дополнить его return)
titleTemplate: ':title | BiXBiT Docs',
sitemap: { hostname: 'https://docs.bixbit.io' },
// внутри существующего transformHead({ pageData }) добавить:
const rel = pageData.relativePath, isRu = rel.startsWith('ru/')
const base = (isRu ? rel.slice(3) : rel).replace(/(^|\/)index\.md$/, '$1').replace(/\.md$/, '.html')
const en = `https://docs.bixbit.io/${base}`, ru = `https://docs.bixbit.io/ru/${base}`
// ...и в массив, который возвращает функция:
['link', { rel: 'alternate', hreflang: 'en', href: en }],
['link', { rel: 'alternate', hreflang: 'ru', href: ru }],
['link', { rel: 'alternate', hreflang: 'x-default', href: en }],
['meta', { property: 'og:site_name', content: 'BiXBiT Docs' }],
['meta', { property: 'og:url', content: isRu ? ru : en }]

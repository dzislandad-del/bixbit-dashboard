## Правила, по которым писалось

- Title ≤ 60 символов, description 140–160, все уникальны внутри локали (проверено скриптом). H1 уникальны внутри локали.
- EN — американский B2B-английский, повелительное наклонение для инструкций. RU — нативный русский, в сниппетах разговорные формы из GSC («асик», «как узнать IP»).
- Все цифры, коды и названия кнопок взяты с самих страниц: 2000 W, 12.5–14 / 14.5–15.5 V, 25 mm², 2200 W, 3900–4000 W, 138.57 TH/s, 13 декабря 2023, chip_temp_target 115, коды 540–542, 701, 2010, 560, 901. Ничего не добавлено сверх текста.
- Dev fee: только на FAQ, как «transparent dev fee» / «прозрачная комиссия» + `[VERIFY: current rate]`. Hotel Fee — функция прошивки для клиента, с dev fee не смешивается.
- Номера разделов (3.1, 6.4…) оставлены в H1 для навигации по руководству. В title их нет: в выдаче они не помогают.
- RU-страница кодов ошибок: title, description и H1 взяты **без изменений** из `content/briefs/ru/ru-whatsminer-error-codes.md`. Её [VERIFY] перенесены в примечание.
- Длина считается в символах Unicode. У кириллицы пиксельная ширина больше: при обрезке в выдаче первыми срезаются хвосты после двоеточия, ключ стоит в начале.
